# 燕云Token获取小工具 (yysls-token)

> 🚀 一款基于本地代理技术，用于《燕云十六声》PC端微信小程序认证 `access_token` 的辅助提取工具。仅用于本地调试与自动化授权场景。

## 📖 项目简介

本工具是一款基于 .NET 8 开发的 Windows 桌面辅助程序。其通过运行本地 HTTP/HTTPS 代理服务，在用户授权的前提下，监听指定游戏服务域名的网络请求，并从中提取用于身份验证的 `access_token`。工具具备自动配置与还原本地网络环境的能力，确保操作过程对用户正常网络使用无干扰。

## ✨ 核心功能

- ✅ **环境检测机制**：启动时自动检测 PC 版微信进程，确保小程序运行环境就绪。
- ✅ **自动化网络配置**：一键启动本地代理服务，并自动设置系统网络代理参数。
- ✅ **TLS 安全解析**：自动安装本地受信根证书，实现对指定加密网络流量的合规解析。
- ✅ **精准目标过滤**：仅对 `s3.game.163.com` 及特定路径的 API 请求进行监听与解析。
- ✅ **代理状态自动还原**：监听任务完成后，自动将系统网络代理恢复至启动前的原始状态。
- ✅ **便捷结果输出**：解析到的 Token 会显示在界面并支持一键复制至剪贴板。

## 🛠️ 使用方法

1. **下载与运行**：自行编译。
2. **确认微信状态**：请确保 PC 版微信已启动并完成登录。
3. **启动代理服务**：
   - 点击主界面的 **“开始捕获”** 按钮。
   - 若首次使用，系统会提示安装本地 CA 根证书（用于解析 HTTPS 流量），请点击“是”以完成信任配置。
4. **进入小程序**：
   - 工具会自动尝试拉起微信中的 **“燕云十六声官方”** 小程序（优先使用桌面快捷方式）。
   - 若自动拉起失败，请手动在 PC 微信中搜索并打开该小程序。
5. **获取授权 Token**：
   - 在小程序中进行常规操作，工具在监听到相关 HTTP 请求并解析出 `access_token` 后，状态栏会弹出成功提示。
   - Token 内容会显示在输入框内，点击 **“复制 Token”** 即可使用。
6. **停止监听**：点击主界面的 **“停止捕获”** 或 **“重新捕获”**，网络代理设置将恢复原状。

## ⚙️ 技术原理

1. **本地代理服务**：基于 `CaptureProxy` 库在本地开启 TCP 监听端口（范围：8877~8887），并更新 Windows 注册表以指定系统代理指向该端口。
2. **流量转发与解析**：代理服务接收本地应用程序发出的网络请求。对于匹配目标域名的 HTTPS 请求，利用已安装的本地 CA 证书进行解密并读取内容。
3. **正则表达式提取**：解析目标 API 请求的 URL 查询参数，匹配 `[?&]access_token=([^&\s#]+)` 以提取鉴权信息。
4. **环境恢复**：监听结束后，读取出启动时保存的原始代理状态并写回注册表，调用系统 API 刷新网络设置，确保后续网络畅通。

## 🔧 技术栈与配置

- **开发框架**：.NET 8 (Windows Forms)
- **运行环境**：Windows 10 / 11 (x64)
- **核心依赖**：[CaptureProxy](https://www.nuget.org/packages/CaptureProxy) (提供本地代理及 TLS 中间人解析能力)
